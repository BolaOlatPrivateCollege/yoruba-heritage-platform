# Security and reporting

This is an early-stage heritage archive. The bundled `server.py` is a **local pilot only**, not a public production service. Never expose it directly to the Internet. There are no production credentials included in this repository.

Until a moderator workflow and privacy/security review have passed, treat submitted oral testimony, identities, contact details, recordings, family histories and medical claims as potentially sensitive. Public article review and forum moderation are separate editorial responsibilities. Never publish or redistribute contributed records without provenance, rights and appropriate consent.

Report suspected security issues privately to the project repository owner. Do not submit sensitive issue details through public comments or discussions.
