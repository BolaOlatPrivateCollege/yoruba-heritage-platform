# Àṣà & Ìtàn Yorùbá — Historical Visual House Style
**Approved visual direction: 23 November 2026.**

## Standard
Images depicting historical Yorùbá life, traditional craft production, early markets, past-era palace and town scenes, and historical or legendary settings must use **black-and-white, greyscale or restrained sepia**. No vivid cinematic colourisation, saturated fabrics or modern teal/orange grading in these images. Natural faded silver-gelatin, worn photographic paper and subtle archive textures may be used where appropriate.

This is an **art direction**, not an assertion that every historic event was photographed without colour. Historical photographs must preserve provenance and must not be silently altered or passed off as documents showing an invented reconstruction.

## Authenticity rules
1. **Actual archival photography:** preserve an unaltered master. Show the original or an editorial monochrome display copy, never change the historical evidence itself. Credit creator, date, institution/holder, rights and place where known. Do not remove watermarks, provenance marks or ownership marks from sourced images.
2. **AI-generated historical scene:** apply the same monochrome/sepia visual style, but **never present it as an actual period photograph**. Place a visible caption such as “AI-generated historical-style illustration; not an archival photograph or verified reconstruction.” Aged paper, grain, edge wear and sepia are stylistic only; avoid fake dates, documentary archive stamps, misleading labels or false credits.
3. **Oral tradition, òrìṣà, ceremony and sacred settings:** use respectful imagery, do not invent sacred paraphernalia and claim it is historically verified. Review accuracy with cultural custodians before release. Separate dramatic retellings from authenticated testimony.
4. **Contemporary photos:** retain true colour if showing living people or current events. Modern interface elements can have an accessible colour palette. New modern photos should not be artificially antiqued to imply historic age.
5. **Accessibility:** alt text should describe what is actually shown. An invented image must state its illustrated nature in the caption or adjacent text. Keep text outside the image whenever possible for translation, screen readers and mobile legibility.

## Web implementation
- `heritage-visual heritage-visual--historical` is a reusable CSS class pair for historical **illustrations**, with greyscale and subtle sepia colour processing. It is not automatically applied to photographs.
- `heritage-visual--archive-original` is for original archival photographs; no filter by default so documentary originals remain unchanged.
- `heritage-visual--modern` explicitly leaves contemporary photography untreated.
- The existing CSS-generated homepage evening storytelling illustration is historical-style fiction and is now rendered in greyscale/sepia.
- New imagery must be reviewed for origin, date, rights, distinguishing captions, attire/material culture and any doubtful reconstruction before deployment.
- Do not recolour earlier documentary archive images in bulk. Review them individually.
